# Rol

Actúa como un equipo completo de una empresa tecnológica formado por:

- CEO / Fundador
- CTO (Chief Technology Officer)
- VP de Ingeniería
- Product Manager
- Business Analyst
- Software Architect
- UX/UI Designer
- Frontend Lead
- Backend Lead
- Mobile Lead
- QA Lead
- DevOps Lead
- Security Engineer
- Data & AI Lead
- Technical Writer

Tu objetivo es crear una página web profesional que presente nuestra empresa, servicios y capacidades tecnológicas de manera clara para clientes no técnicos.

# Objetivo principal

Diseñar una página web corporativa moderna, elegante y confiable que permita a un cliente entender:

- Quiénes somos.
- Qué problemas resolvemos.
- Qué servicios ofrecemos.
- Cómo trabajamos.
- Qué tecnologías utilizamos.
- Por qué elegirnos.
- Cómo contactarnos.

El cliente final NO debe ver una estructura técnica complicada. Debe entender beneficios y resultados.

# Público objetivo

Diseña pensando en:

- Empresarios.
- Empresas medianas y grandes.
- Emprendedores.
- Clientes que buscan desarrollar software.
- Personas no expertas en tecnología.

Evita lenguaje excesivamente técnico.

# Rol del CEO

Define:

- Propuesta de valor.
- Misión.
- Visión.
- Mensaje corporativo.
- Diferenciadores.

# Rol del Product Manager

Define:

- Estructura de la página.
- Recorrido del usuario.
- Llamadas a la acción.
- Mensajes orientados a conversión.

# Rol del Business Analyst

Convierte servicios técnicos en beneficios comerciales.

Ejemplo:

No decir:
"Desarrollamos microservicios con Kubernetes"

Decir:
"Construimos plataformas escalables preparadas para crecer junto con tu negocio."

# Rol UX/UI Designer

Diseña:

- Experiencia de usuario.
- Jerarquía visual.
- Colores.
- Tipografía.
- Espaciados.
- Componentes.
- Diseño responsive.

La página debe transmitir:

- Confianza.
- Innovación.
- Profesionalismo.
- Seguridad.
- Tecnología avanzada.

# Estructura recomendada de la página

Crear:

## 1. Hero Section

Debe incluir:

- Título impactante.
- Subtítulo claro.
- Botón principal.
- Imagen o animación sugerida.

Ejemplo:

"Transformamos ideas en soluciones digitales escalables"

CTA:
"Solicitar asesoría"

---

## 2. Sobre nosotros

Explicar:

- Experiencia.
- Filosofía.
- Forma de trabajo.
- Compromiso con calidad.

---

## 3. Servicios

Presentar de forma comercial:

### Desarrollo Web

Beneficio:
"Aplicaciones web rápidas, seguras y preparadas para crecer."

### Desarrollo Backend

Beneficio:
"Sistemas robustos que soportan procesos críticos."

### Aplicaciones móviles

Beneficio:
"Experiencias móviles modernas para Android e iOS."

### Diseño UX/UI

Beneficio:
"Interfaces intuitivas que mejoran la experiencia del usuario."

### Cloud & DevOps

Beneficio:
"Infraestructura segura, estable y escalable."

### Inteligencia Artificial y Datos

Beneficio:
"Transformamos datos en decisiones inteligentes."

### Seguridad

Beneficio:
"Protegemos tus sistemas y tu información."

---

## 4. Nuestro proceso

Mostrar:

1. Descubrimiento
2. Diseño
3. Desarrollo
4. Pruebas
5. Lanzamiento
6. Soporte y evolución

---

## 5. Nuestra tecnología

Mostrar tecnologías como respaldo, no como el mensaje principal.

Ejemplo:

Frontend:
React, Angular, Vue

Backend:
.NET, Java, Node.js, Python

Mobile:
Android, iOS

Cloud:
AWS, Azure, Google Cloud

Datos:
SQL, NoSQL, IA

---

## 6. Calidad y seguridad

Explicar:

- Pruebas automatizadas.
- Buenas prácticas.
- Seguridad.
- Monitoreo.
- Alta disponibilidad.

---

## 7. Casos de uso

Crear ejemplos:

- Sistemas empresariales.
- Plataformas SaaS.
- Aplicaciones móviles.
- Automatización.
- Inteligencia artificial.

---

## 8. Contacto

Crear una sección de conversión:

- Formulario.
- Botón WhatsApp.
- Solicitud de reunión.
- Email.

# Diseño técnico

Genera:

- Diseño moderno estilo empresa tecnológica.
- Responsive Mobile First.
- Animaciones suaves.
- Excelente rendimiento.
- SEO optimizado.
- Accesibilidad WCAG.

# Stack recomendado

Genera la implementación usando:

Frontend:
- Next.js
- TypeScript
- Tailwind CSS
- Framer Motion

UI:
- Componentes reutilizables.
- Diseño limpio.
- Arquitectura escalable.

# Nivel

Actúa como una agencia tecnológica profesional encargada de crear la página web oficial de una empresa de software internacional.

La página debe vender confianza y resultados, no solamente mostrar tecnología.
