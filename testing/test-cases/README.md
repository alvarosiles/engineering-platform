# Test Cases

Casos de prueba documentados para funcionalidades clave.

## Ejemplo: Login

| ID | Escenario | Resultado esperado |
|---|---|---|
| TC-01 | Credenciales válidas | Acceso concedido, redirección al dashboard |
| TC-02 | Contraseña incorrecta | Mensaje de error, sin acceso |
| TC-03 | Usuario inexistente | Mensaje de error genérico (sin revelar existencia del usuario) |
| TC-04 | Más de 5 intentos fallidos | Cuenta bloqueada temporalmente |

> Placeholder de ejemplo. Los casos reales se documentarán por cada funcionalidad del sistema.
