# Design System

Sistema de diseño y librería de componentes reutilizables para todos los productos frontend.

## Contenido (ejemplo)

- Tokens de diseño: colores, tipografía, espaciados.
- Componentes base: botones, inputs, tarjetas, modales.
- Guías de accesibilidad (WCAG).

## Ejemplo de tokens

```json
{
  "color": {
    "primary": "#5b7cff",
    "secondary": "#8b5bff",
    "background": "#0b0f19"
  },
  "spacing": {
    "sm": "8px",
    "md": "16px",
    "lg": "32px"
  }
}
```

> Placeholder de ejemplo. Los componentes reales se irán agregando conforme evolucione el producto.
