# Policies

Políticas de seguridad de la empresa.

## Ejemplo de políticas

- **Gestión de contraseñas:** mínimo 12 caracteres, rotación cada 90 días para cuentas privilegiadas.
- **Control de acceso:** principio de mínimo privilegio, revisión trimestral de permisos.
- **Respuesta a incidentes:** todo incidente de seguridad debe reportarse en menos de 1 hora.
- **Manejo de datos:** los datos personales se cifran en reposo y en tránsito.
