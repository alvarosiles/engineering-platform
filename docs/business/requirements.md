# Requisitos del Negocio (ejemplo)

## Requisitos funcionales

| ID | Descripción | Prioridad |
|---|---|---|
| RF-01 | El sistema debe permitir el registro y autenticación de usuarios. | Alta |
| RF-02 | El sistema debe exponer una API para consumo de terceros. | Alta |
| RF-03 | El sistema debe permitir la gestión de perfiles de empresa. | Media |
| RF-04 | El sistema debe generar reportes de uso y analítica. | Media |

## Requisitos no funcionales

| ID | Descripción |
|---|---|
| RNF-01 | Disponibilidad mínima del 99.9%. |
| RNF-02 | Tiempo de respuesta de API menor a 300ms en el percentil 95. |
| RNF-03 | Cumplimiento de buenas prácticas de seguridad (OWASP Top 10). |
| RNF-04 | Arquitectura responsive, mobile-first. |

## Stakeholders

- CEO / Fundador — visión y prioridades del negocio.
- Clientes finales — usuarios de las plataformas construidas.
- Equipo de ingeniería — implementación y mantenimiento.
